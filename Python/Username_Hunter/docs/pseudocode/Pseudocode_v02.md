# Username_Hunter - Pseudocode V0.2

This document contains the pseudocode of the version 2.0

```
Start

Enter the username 

While username is empty:
   
  Receive username from argument

Select the Social Media 

While no social media is selected:

    Display: Social media is empty
    Select the Social Media 

Run the Social media
Build the URL
Build the request

For each social media:

    Run the Social media
    Build the URL
    Build the request

Show the results 
End

```
